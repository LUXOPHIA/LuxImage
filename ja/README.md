# LuxImage

[English](../README.md)

`LUX.Data.Image` ―― Delphi / FireMonkey 向けの超高解像度画像ライブラリのデモアプリケーション。

FireMonkey の `TBitmap` は GPU とデータを共有するため GPU のテクスチャサイズ制限をそのまま受け、実際には 8,192 × 8,192 画素程度が上限となる。`TLuxImage` は画素をすべて CPU メモリに保持するので、扱える大きさは GPU ではなく RAM で決まる ―― 100,000 × 100,000 画素以上。

## 画面

起動時は何も読み込まれていない。`開く…` で好きな画像を選んで試す。デモに画像は同梱していない ―― 数万画素四方までの画像であれば、このライブラリの用途が分かるはず。読み込みも保存も別スレッドで走るので、ファイルがどれだけ大きくてもウィンドウは操作を受け付け続ける。

- マウス：ホイールを手前に回すとカーソル位置を中心に拡大、左ドラッグでスクロール。等倍を超えると画素が四角として見え（最近傍）、それ未満では線形補間で表示される。
- パネル：
  - `開く…` / `保存…` … 読み込みと保存。PNG と JPEG に両方向で対応。
  - `画素形式` … 次に開くファイルを読み込む先の画素形式（`UInt08` ・ `UInt16` ・ `SFlo16` ・ `SFlo32`）。
  - `全体表示` … 画像全体を窓に合わせる。
  - `等倍 ( 1 : 1 )` … 画像の1画素を画面の1画素で表示する。
  - `ガンマ` … 表示ガンマ `out = in^(1/Gamma)`。既定値は整数形式が 1.0、浮動小数形式が 2.2。
  - `トーンマップ` … Reinhard のトーンマッピング。浮動小数形式では既定で有効。
- パネル下部のラベルには、画像の大きさ・画素形式・現在の倍率・描画中の縮小段が表示される。

## ライブラリ

`LUX.Data.Image` は画素を 256 × 256 のタイルに分けて保持し、縮小ピラミッドを持つ。そのため 100,000² の画像を全景表示しても拡大表示と同じコストで描ける。Skia へ渡すのは可視タイルだけなので、1フレームのコストは画像の大きさではなく窓の大きさで決まる。トーンマッピングとガンマ補正は SkSL のランタイムカラーフィルタとして GPU 上で実行される。

詳細なドキュメント：
[`_LIBRARY/LUXOPHIA/LUX/Data/Image`](../_LIBRARY/LUXOPHIA/LUX/Data/Image/ja/README.md)。

## ビルド

- Delphi (RAD Studio) / FireMonkey + Skia（`GlobalUseSkia = True`。Vulkan バックエンドが自身を登録できるよう `FMX.Skia.Canvas.Vulkan` を uses に入れる）。
- `LuxImage.dproj` を開いて Win64 をビルドする。
- `sk4d.dll` を実行ファイルと同じ場所に置くこと。IDE からビルドすれば RAD Studio が自動で配置する。
